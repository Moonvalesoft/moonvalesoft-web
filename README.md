# Moonvalesoft Web

`moonvalesoft.com`: ürünler ve Logo hizmetleri; teklif için Telegram.

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # statik site: apps/web/out
```

İçerik: `apps/web/lib/site.ts`. Telegram adresi: `apps/web/.env.local` içine `NEXT_PUBLIC_TELEGRAM_USERNAME=kullaniciadi`.
